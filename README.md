# Dark Rose — frontend MVP

Премиальный многостраничный прототип цветочного магазина в стилистике dark floral couture.

## Запуск

Проект не требует сборщика: откройте `index.html` через локальный статический сервер.

Например:

```bash
python3 -m http.server 8080
```

После этого откройте `http://localhost:8080`.

## Что уже работает

- Главная с cinematic 2.5D hero-розой и параллаксом
- Каталог, категории, фильтрация по цене/цвету, сортировка
- Страница товара через `product.html?id=...`
- Корзина на `localStorage`, изменение количества и удаление
- Контакты и формы а demo-режиме
- Экран авторизации в demo-режиме
- Адаптивная навигация
- Reduced motion accessibility
- Обязательная подпись `Created By Deerflow`

## Следующий технический этап

После утверждения визуального направления интерфейс рекомендуется перенести в:

- Next.js + TypeScript
- PostgreSQL + Prisma
- OTP/SMS авторизацию
- API заказов, товаров и адресов
- платежный провайдер РФ / СБП
- CMS или admin-панель
- object storage для фотографий
